📣 ประกาศ

กราฟเปรียบเทียบคะแนนการส่งรายงานรายอำเภอ ()

เกณฑ์คะแนน: 1 รายงาน = 2 คะแนน (คำนวณเฉพาะรายงานที่เปิดส่งในเดือนนี้)

สัดส่วนสถานะการส่งงาน

ประจำเดือน

ตารางสรุปผลการส่งรายงานและคะแนนรายอำเภอ ()

เริ่มต้นเดือนใหม่ที่ 0 งาน — ซิงค์ข้อมูลข้ามเครื่องผ่าน Google Sheets อัตโนมัติ

ความคืบหน้าแยกตาม 4 กลุ่มงานหลัก ()

คลิกที่กลุ่มงานเพื่อเข้าสู่หน้าตารางส่งรายงานและอัปโหลดไฟล์

แดชบอร์ดสรุปคะแนนการส่งงานรายเดือน (มกราคม – ธันวาคม)

ติดตามความก้าวหน้าและคะแนนสะสมรายเดือนของทั้ง 8 อำเภอ (คิดเฉพาะรายงานที่เปิดใช้งานในแต่ละเดือน)

ระบบอนุมัติการส่งงาน, ดาวน์โหลดไฟล์งาน & ให้คะแนนแบบแมนนวล (Manual)

แอดมินจังหวัดสามารถดาวน์โหลดไฟล์ ตรวจอนุมัติ ให้คะแนน หรือกดซ่อน/เพิ่มหัวข้อรายงานของเดือนที่เลือกได้ทันที

📋 ตารางให้คะแนนแบบแมนนวล (เฉพาะหัวข้อที่ต้องส่งในเดือนที่เลือก) — คลิกปุ่ม 2 / 1 / 0 เพื่อบันทึกคะแนนลง Google Sheets ทันที

📑 ตารางตรวจสอบ, ดาวน์โหลดไฟล์งานจาก Google Drive และอนุมัติการส่งรายงาน

🗂️ จัดการหัวข้อการรายงาน 4 กลุ่มงาน & กำหนดการเปิด/ซ่อนรายงานประจำเดือน (เฉพาะ Admin)

สามารถเพิ่มหัวข้อการส่งงานใหม่ แก้ไขชื่อ หรือกดซ่อน/ไม่ต้องส่งรายงานบางตัวในแต่ละเดือนได้อิสระ และบันทึกลง Google Sheets อัตโนมัติ

💡 วิธีใช้งานการซ่อน/เปิดรายงานรายเดือน: เดือนไหนที่มีงานส่งเท่าเดิมไม่ต้องปรับอะไร หากเดือนถัดไปไม่ต้องส่งงานตัวไหน ให้คลิกปุ่ม 🙈 ซ่อนเดือนนี้ หรือคลิกที่ชื่อเดือนในตารางด้านล่างเพื่อเปลี่ยนเป็นสถานะงดส่ง และหากเดือนถัดไปมีการเพิ่มหัวข้อส่งงานใหม่ สามารถกดปุ่ม "➕ เพิ่มหัวข้อรายงานใหม่" ได้ทันที

🗓️ กำหนดวันและเวลาส่งรายงานประจำเดือน (เฉพาะ Admin)

เลือกเดือนและกลุ่มงาน ตั้งวัน–เวลาที่ต้องส่งแต่ละหัวข้อ พร้อมหมายเหตุ แล้วกดบันทึกรายหัวข้อ อำเภอจะเห็นกำหนดส่งในหน้ารายงาน

ตั้งวัน–เวลาได้อิสระ (วันและปี พ.ศ./ค.ศ. ตามตัวเลือกของเครื่อง) กำหนดเวลาที่พ้นแล้วจะแสดงว่าเกินกำหนด แต่ยังส่งแก้ไขได้ตามระบบเดิม

📣 ตั้งค่าข้อความวิ่งหน้าเว็บไซต์

ข้อความที่ตั้งจะปรากฏใต้แถบเลือกเดือนของผู้ใช้งานทุกอำเภอ และบันทึกลง Cloud

👁️ ตัวอย่าง

ข้อความตัวอย่างด้านบนยังไม่เผยแพร่จนกว่าจะกดบันทึก

ยังไม่ได้ตรวจสอบข้อมูลประกาศบน Google Apps Script
🔌 ตรวจสอบ Apps Script ปลายทาง (V20)

หากขึ้นว่าเป็นเวอร์ชันเก่า ให้คัดลอก URL เว็บแอปที่ Deploy ล่าสุดซึ่งลงท้ายด้วย /exec มาใส่ด้านล่าง แล้วกดตรวจสอบและเชื่อมต่อ

รอการตรวจสอบเวอร์ชัน Apps Script

🔑 จัดการและเปลี่ยนรหัสผ่านให้อำเภอ & ผู้ดูแลระบบ (เฉพาะ Admin จังหวัดเท่านั้น)

เมื่อแอดมินเปลี่ยนรหัสผ่านและกดบันทึก ระบบจะซิงค์ขึ้น Cloud ทันที ทำให้อำเภอใช้รหัสผ่านใหม่เข้าสู่ระบบได้จากทุกเครื่อง

🔐 สิทธิ์เฉพาะแอดมินจังหวัด (Admin): คุณสามารถแก้ไขรหัสผ่านของทั้ง 8 อำเภอ (UTI01 – UTI08) และรหัสของ Admin ได้ในตารางด้านล่าง เมื่อแก้ไขแล้วกดปุ่ม "💾 บันทึก" ระบบจะอัปเดตลงฐานข้อมูลทันที

🤖 ตั้งค่าบอท LINE OA & ตรวจสอบสถานะการเชื่อมต่อ

วาง Channel access token (long-lived) จากเว็บ LINE Developers ที่ช่องด้านล่างนี้ แล้วกดปุ่มตรวจสอบและบันทึก

⏳ รอตรวจสอบ Token
กำลังตรวจสอบ Token ที่บันทึกไว้บน Cloud...
💡 วิธีให้บอท LINE ส่งแจ้งเตือนเข้ากลุ่มอำเภอได้จริง 100%:
1. วาง Channel Access Token ด้านบนแล้วกดปุ่ม "🔍 ตรวจสอบบอท & บันทึก Token" (ระบบจะแสดงชื่อบอทของคุณขึ้นมา)
2. รหัสไอดีที่ใช้ส่งผ่านบอทต้องเป็นรหัส 33 ตัวอักษรที่ขึ้นต้นด้วย U... (บุคคล) หรือ C... (กลุ่มไลน์) เท่านั้น — วิธีดูรหัสง่ายๆ: เชิญบอทเข้ากลุ่มไลน์ของอำเภอแล้วพิมพ์คำว่า id ในกลุ่ม บอทจะตอบกลับรหัส C... ทันทีและดึงเข้าตารางด้านล่างให้อัตโนมัติ!

➕ บันทึกและผูกไอดีไลน์ประจำอำเภอ

ผูกไอดีไลน์เข้ากับแต่ละอำเภอ เพื่อเลือกส่งเฉพาะอำเภอหรือเลือกตามไอดีได้ทันที

แก้ชื่อผู้รับแล้วกดบันทึก ระบบจะรอการยืนยันจาก Google Sheets
📋 รายชื่อไอดีที่บันทึกไว้ (ติ๊ก ☑️ เพื่อเลือกส่งได้)

📢 เมนูเลือกอำเภอและเลือกไอดีที่จะส่งรายงานทาง LINE

เลือกส่งเฉพาะอำเภอตามไอดีที่กำหนด หรือเลือกส่งเฉพาะไอดีที่ต้องการได้ทันที

📑 รายการรายงานประจำเดือน

กลุ่มงาน

ตารางส่งรายงานประจำเดือน อัปโหลดไฟล์เข้า Google Drive แยกตามกลุ่มงาน (ไม่เกิน 5 MB) และบันทึกลง Google Sheets อัตโนมัติ

📥 นำเข้าข้อมูลการส่งรายงานประจำเดือนด้วย Excel / Google Sheets

เฉพาะแอดมินระดับจังหวัด (Admin) เท่านั้น และต้องยืนยันรหัสลับก่อนนำเข้าข้อมูลหรือรีเซ็ตระบบ

🔐 ระบบป้องกันความปลอดภัยระดับจังหวัด: การนำเข้าข้อมูลด้วยไฟล์ Excel และการรีเซ็ตข้อมูลเป็นค่าเริ่มต้น อนุญาตให้เฉพาะ Admin จังหวัด เท่านั้น และต้องกรอกรหัสผ่านชั้นที่ 2 ก่อนดำเนินการทุกครั้ง
📊

คลิกเพื่อเลือกไฟล์ Excel (.xlsx, .csv) หรือลากไฟล์มาวางที่นี่

ระบบจะขอรหัสยืนยันความปลอดภัยก่อนนำเข้าข้อมูลและซิงค์ขึ้น Google Sheets อัตโนมัติ

🔗 เชื่อมต่อฐานข้อมูล Google Sheets, Google Drive & LINE Messaging API (เฉพาะ Admin จังหวัด)

บันทึกค่าการเชื่อมต่อและ LINE Channel Access Token ไว้ที่ฐานข้อมูลกลางของจังหวัด
